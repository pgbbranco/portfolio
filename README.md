## Organização

- `site/index.html`: apresentação, estilos e interações do site.
- `entregas/`: imagens de apresentação dos projetos.
- `site/fundo.jpg`, `site/image.jpg`, `site/musica.mp3`: recursos usados pelo site.
- Documentação e arquivos completos de cada entrega ficam no repositório do projeto.

Ao publicar uma nova entrega, adicione os materiais ao repositório correspondente e atualize o link do card no site.

[Todos os repositórios](https://github.com/pgbbranco)

O `index.html` da raiz apenas encaminha para `site/`, mantendo o endereço original.
